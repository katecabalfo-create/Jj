# Maldo Buzz Hub

Landing page estática (HTML + CSS + JS, sin dependencias).

- `index.html` — estructura de la página
- `styles.css` — estilos, tema claro/oscuro y diseño responsive
- `script.js` — tarjetas de tendencias, filtros, likes, menú móvil y newsletter

Para verla, abre `index.html` en el navegador. Para publicarla, sirve la carpeta en cualquier hosting estático (GitHub Pages, Netlify, Vercel).
